## THE RANGE MAP (chapter 4 — one idea into a connected range)

A range is a **portfolio of connected bets**, all aimed at the same
buyer. Draft 2–3 new pieces that belong with what already works.

### Run each draft through three gates
For each, tick only if it honestly passes:

                                    Draft A   Draft B   Draft C
  THROUGH-LINE (same buyer/feeling)   [ ]       [ ]       [ ]
  RECOGNITION (reads as "my shop")    [ ]       [ ]       [ ]
  PRODUCT-FIT (right blank for it)    [ ]       [ ]       [ ]

A draft that fails a gate isn't a range piece yet — it's a
different shop. Keep the range narrow and deep, not wide.

⚠️ These are connected *bets to test*, not sure things — the
market's verdict comes later (chapters 7–8), off real numbers.
