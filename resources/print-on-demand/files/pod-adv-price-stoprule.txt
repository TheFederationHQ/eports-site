PRICE + STOP RULE — set both, before you list (chapter 4)

Set the price the honest way, and the rule that lets you HOLD it.

FIND THE CANDIDATE PRICE (value first, then check):
  1 What this buyer already pays around the ritual (the ecosystem):
      ________________________________________________________
  2 Place my HERO product inside that world (below/above what?):
      ________________________________________________________
  3 FLOOR: it must clear build cost + fees with real room.
  4 Candidate price (value-led): £__________

LOADED CHECK — price minus ALL costs (base, pkg, ship, platform %,
buffer, fixed, then time + returns) = leaves: £__________
  check it: eports.global/tools/print-on-demand-allocation

⚠ COUPON MATH (get it right): a % coupon also lowers the % platform
fee, so the true hit = discount x (1 - fee%), NOT the full discount.
(15% off £68 at 13% fee = £8.87 lost, not £10.20.)

STOP RULE — decided NOW, while calm (fix the pass line before you
look at any result):
  Window: ______ days AND about ______ qualified visits (later of)
  Pass line (full-price sales), set in advance: ______
  While the window is open I will NOT: ____________________
    (honest default: cut price / run a coupon)
  If it FAILS after fair exposure: ONE offer revision (photos,
    story, buyer), re-test same terms, then DELIST. Never a cut.

Date it. Tape it where you will see it. A rule in a drawer is a wish.
