ETSY - CONVERSION: THE SILENT-WORRIES AUDIT + EVIDENCE CYCLE  (Chapter 6)

Conversion is trust, built at a distance. Every element on the page either
answers a silent worry or leaves it open. Close the worries; earn reviews
the compliant way; then test ONE change - patiently, because orders are rare.

  THE SILENT-WORRIES AUDIT - can a stranger resolve each without messaging?
    What will arrive?    (photos show the real item)        [ ]
    How big is it?       (a scale shot / stated dimensions)  [ ]
    Is the quality real? (detail shots, honest light)        [ ]
    When will it come?   (processing + delivery stated)         [ ]
    What if it's wrong?  (a clear, calm return policy)        [ ]
    Has anyone been glad?(reviews present)                   [ ]
    Any box unchecked = a worry left open = likely friction.

  REVIEWS - the line you must not cross:
    Deliver an experience worth reviewing; a genuine thank-you note that
    asks for NOTHING. Let Etsy send the review prompt. Do NOT message
    buyers fishing for a review, and NEVER condition a discount, gift or
    refund on one. Manipulated/incentivized reviews can cost the account.

  CONVERSION EVIDENCE CYCLE (sequential; needs a BIG sample):
    Listing: ___________________  baseline conv% (orders/visits): ______
    PRE-SET MINIMUM before I judge: ____ visits AND ____ orders
      (or a max window from my contract) - else "can't test yet".
    THE ONE CHANGE (a bundle, judged as one):
      [ ] photo set   [ ] description   [ ] price framing   (reviews = earn)
    Window: fixed + long (orders are rare); compare like periods.
    VERDICT:  supports  /  contradicts  /  inconclusive
      INCONCLUSIVE (the default) if below the minimum, the traffic mix
      shifted, or the whole shop moved.
