Where it's used

Where you'll need this code

  1. SBA loans and contractsThe Small Business Administration sets its size standards by NAICS code, so your code decides whether you count as "small" for its loans and set-aside contracts.
  2. Federal and state registrationSAM.gov (for selling to the US government) asks for your NAICS codes, and many state business filings and licenses ask for one too.
  3. Tax formsSchedule C and business tax returns ask for a "principal business activity code". The IRS list is based on NAICS but shorter, so check the code in the form's own instructions.
  4. Banks, insurers and grantsLenders, insurers and grant programs use the code to see what you do, so the wrong one can mean a higher premium or a missed grant.
FAQ

Questions about 445

What is NAICS code 445?

445 is the 2022 NAICS subsector "Food and Beverage Retailers". It sits in sector 44-45 (Retail Trade) and holds 10 six-digit industry codes, listed on this page.

Which code should I use, 3-digit or 6-digit?

Use the 6-digit code wherever a form asks for a NAICS code. The shorter codes are the groups those 6-digit codes belong to.

What is the 6-digit code for Supermarkets and Other Grocery Retailers (except Convenience Retailers)?

It is 445110, under 445 Food and Beverage Retailers, in the 2022 NAICS list published by the US Census Bureau.

Can a business have more than one NAICS code?

Yes. You pick one primary code for the activity that earns the most, and some forms, such as SAM.gov, let you list others too.
